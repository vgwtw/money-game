# 錢的三道關卡

課堂互動遊戲：全班一起闖三關，認識活動的預算、報價與贊助。

**線上玩：** https://vgwtw.github.io/money-game/

## 怎麼玩

講師把網頁投影出來，全班舉手表決，講師負責點選。

1. **猜猜多少錢**：8 個活動常見的開銷（主持人、工讀生、保險、舞台……），全班猜價錢。價格是業界行情的示意，各地差很多。
2. **報價單找碴**：一張校園演唱會的報價單，藏了 7 個真正的問題和 4 個陷阱。公布後會算出改好之後真正的總價。
3. **贊助配對**：4 個品牌想贊助，嘴上說的和心裡想的不一樣。每個品牌只能給 2 項權益，猜中他真正要的，錢才會進來。

最後有結算頁和收尾問題。只有一個 `index.html`，不需要安裝任何東西。進度存在瀏覽器裡，重新整理不會不見。
